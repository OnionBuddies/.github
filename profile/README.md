OnionBuddies is an open source organization building plugins and
tooling around **OnionHEN**, a homebrew environment for PlayStation 5. We
focus on keeping things small, modular, and easy to build with — so anyone
can write and share their own plugin.

> This is the organization profile. The OnionHEN host-side project is separate
> work; here you will find the plugin SDK and plugins built on top of it.

## Projects

- [onionHEN-plugin-sdk](https://github.com/OnionBuddies/onionHEN-plugin-sdk) — the official SDK for building OnionHEN plugins. **Start here.**
- [onionHEN-ftpsrv-plugin](https://github.com/OnionBuddies/onionHEN-ftpsrv-plugin) — an OnionHEN plugin wrapper for `ftpsrv`.
- [onionHEN-overlay-plugin](https://github.com/OnionBuddies/onionHEN-overlay-plugin) — an overlay plugin for OnionHEN.

## Get involved

Contributions of all kinds are welcome: code, documentation, testing, ideas,
or just questions. Please read the
[contributing guide](https://github.com/OnionBuddies/onionHEN-plugin-sdk/blob/main/CONTRIBUTING.md)
and our
[code of conduct](https://github.com/OnionBuddies/onionHEN-plugin-sdk/blob/main/CODE_OF_CONDUCT.md)
first, then jump in. If you have a question, open a
[discussion](https://github.com/OnionBuddies/onionHEN-plugin-sdk/discussions)
or an issue in the relevant repository.
