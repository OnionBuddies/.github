OnionBuddies 是一个围绕 **OnionHEN**（PlayStation 5 的 homebrew 环境）构建开源
插件与工具的开发社区。我们追求轻量、模块化、易构建，让每个人都能编写和
分享自己的插件。

> 本文件是组织介绍。OnionHEN 宿主侧项目属于独立工作；这里收录的是插件
> SDK 以及基于它构建的插件。

## 项目

- [onionHEN-plugin-sdk](https://github.com/OnionBuddies/onionHEN-plugin-sdk) — 构建 OnionHEN 插件的官方 SDK。**从这里开始。**
- [onionHEN-ftpsrv-plugin](https://github.com/OnionBuddies/onionHEN-ftpsrv-plugin) — 基于 `ftpsrv` 的 OnionHEN 插件封装。
- [onionHEN-overlay-plugin](https://github.com/OnionBuddies/onionHEN-overlay-plugin) — OnionHEN 的 overlay 插件。

## 参与贡献

欢迎各种形式的贡献：代码、文档、测试、想法，或者仅仅是提问。请先阅读
[贡献指南](https://github.com/OnionBuddies/onionHEN-plugin-sdk/blob/main/CONTRIBUTING.md)
和[行为准则](https://github.com/OnionBuddies/onionHEN-plugin-sdk/blob/main/CODE_OF_CONDUCT.md)，
然后就可以参与进来。如有疑问，可以在
[Discussion](https://github.com/OnionBuddies/onionHEN-plugin-sdk/discussions)
或对应仓库的 Issue 中提出。
